Login page kustom dengan nama template & slug login yang bisa diatur dari Settings. Semua pengaturan dinamis tanpa perlu edit kode.

== Description ==

Fitur:
* Nama template & slug login bisa diatur dari Settings (dinamis)
* Login page kustom dengan desain modern
* Redirect after login ke dashboard-admin
* Redirect after logout ke homepage
* Blokir wp-admin untuk non-logged-in users
* Default homepage opsional
* Integrasi otomatis dengan WPS Hide Login (sinkron whl_page)
* Ikon plugin, login & logout yang bisa di-replace dari folder /assets/
* Shortcode [clr_logout_button] untuk tombol logout

== Installation ==

1. Upload folder ke /wp-content/plugins/custom-login-redirect/
2. Aktifkan plugin dari menu Plugins
3. Buka Settings > Custom Login & Redirect
4. Atur nama template, login URL slug, dan redirect
5. Buat halaman baru, pilih template dari Page Attributes
